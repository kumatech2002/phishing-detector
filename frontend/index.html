About PhishShield NG

How the detection system works

🧠

Machine Learning Models

Two classifiers are trained and compared — a Random Forest and a Gradient Boosting classifier (both from scikit-learn). The best-performing model by ROC-AUC on held-out test data is saved as the active classifier.

🔬

Feature Extraction

37 domain-level features are extracted from each domain including structural metrics (length, hyphens, digits), brand similarity scores (Levenshtein distance, Jaro-Winkler), TLD risk scores, and suspicious keyword detection.

🏦

Target Banks

The model is trained to detect impersonation of 10 major Nigerian banks: Access Bank, GTBank, First Bank, UBA, Zenith Bank, Fidelity Bank, Union Bank, Ecobank, Stanbic IBTC, and Polaris Bank.

⚠️

Important Disclaimer

This system analyses domains using lexical features only — no network requests are made to the target domain. Predictions are probabilistic and should never be treated as a guarantee that a domain is safe or malicious. Always verify through official bank channels.

📊

Dataset

The model is trained on a synthetic benchmark dataset of ~5,000 labelled domains generated from 8 realistic phishing attack patterns (typosquatting, homoglyph substitution, subdomain camouflage, hyphenation, TLD swapping, keyword stuffing, random-suffix, and multi-technique combinations).

🔒

Security

All analysis is purely lexical — the system never visits or resolves the domain being analysed. API endpoints are rate-limited, all database queries are parameterised, and no credentials or session data are stored.
